# Security policy

Please do not report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting feature for this repository if it is enabled. Otherwise, contact the repository owner privately through GitHub. Include reproduction details that are safe to share, and avoid attaching credentials, private traffic-camera footage, personal data, or sensitive infrastructure information.

Clear Flow is an experimental research project and is not approved for direct control of real-world traffic signals. Do not connect experimental policies to live traffic-control equipment.
