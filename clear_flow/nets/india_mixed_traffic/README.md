# India mixed-traffic starter scenario

This is a synthetic research scenario for testing heterogeneous vehicle demand in Clear Flow. It uses the simple inherited four-arm network at `clear_flow/nets/single-intersection/single-intersection.net.xml` and defines separate vehicle types for two-wheelers, auto-rickshaws, cars, buses, and trucks.

The network geometry is not a surveyed Indian junction. All dimensions, behavioural parameters, and departure rates are starter assumptions. Calibrate the vehicle mix, turning movements, traffic demand, lane geometry and driving behaviour with local observations before reporting real-world conclusions. The initial route set uses straight movements only; it is not a complete urban traffic model.
